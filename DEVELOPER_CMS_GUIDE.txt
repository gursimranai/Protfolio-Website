3. DATABASE SCHEMA & AUTHORIZATION SETUP (supabase-schema.sql)
--------------------------------------------------------------------
To run or re-apply database security:
  1. Go to Supabase Dashboard: https://supabase.com/dashboard/project/bufvzcvlmibayhwgvnsr
  2. Click "SQL Editor" in the left navigation.
  3. Click "+ New Query".
  4. Copy and paste the entire content of `supabase-schema.sql`.
  5. Click "RUN".

Database Architecture:
  - `public.profiles` Table:
      Columns: id (UUID), email (TEXT), role (TEXT), created_at, updated_at
      Auto Trigger: Assigns role='admin' to gursimranaidev@gmail.com and 'user' to others.
      RLS Rule: Users CANNOT alter their own role column from the frontend.

  - `public.articles` Table:
      Columns: id, title, slug, description, author, content, category, type, tags, cover_image, read_time, word_count, status, published, scheduled_at, created_at, updated_at, seo_title, seo_description
      RLS Rule (Public): Can ONLY SELECT rows where published = true AND status = 'Published'.
      RLS Rule (Admin): Only authenticated user with role='admin' can SELECT all (drafts), INSERT, UPDATE, or DELETE.
